# RUNO Clothing — Demo website

A responsive storefront concept built with HTML, CSS, Bootstrap 5 and vanilla JavaScript. The catalog, prices, images, descriptions and sizes are placeholders; this is not an official RUNO Clothing website.

## Run it in VS Code

1. Extract `runo-clothing-demo.zip`.
2. Open VS Code.
3. Choose **File → Open Folder...** and select the `runo-clothing-demo` folder.
4. Open `index.html`.
5. Recommended: install the **Live Server** extension by Ritwick Dey, right-click `index.html`, and choose **Open with Live Server**.
6. The page should open in your browser. Changes to HTML/CSS/JS will refresh automatically.

You can also open `index.html` directly in your browser, but Live Server is more convenient while developing.

## Before showing it to the seller

- Confirm the real brand logo, colors, product categories and preferred language from the seller's Instagram.
- Replace the demo products in `script.js` with approved product photos, names, sizes, descriptions and prices.
- Replace `WHATSAPP_NUMBER` near the top of `script.js` with the seller's real WhatsApp number in international format, digits only. Example format: `3834XXXXXXXX` for a Kosovo number. Do not leave the `X` characters.
- Update delivery fees, delivery areas, returns/exchanges and contact details only after the seller confirms them.
- Get permission to use the seller's brand assets and product photographs.
- Test the order form on mobile and desktop. It opens WhatsApp with a pre-filled message; the customer must press Send in WhatsApp.
- This demo has no database, admin dashboard, stock sync, or online payments. The cart exists only in the current browser session.

## Product image notes

Demo images load from Unsplash over the internet. Replace them with the seller's approved photos for the final version. Product names and prices in this demo are fictional and must not be presented as real inventory.

## Suggested client scope (€150–€250)

For a small first version, agree in writing on the number of products, pages, language, order method, delivery information, revision rounds, launch date and who pays for the domain/hosting. A simple static catalog with WhatsApp orders is different from a full e-commerce platform with inventory and administration.
